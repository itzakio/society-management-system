# Society Management System

A multi-tenant Society Management System built with the MERN stack.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- TanStack Query

### Backend
- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- JWT
